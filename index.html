Overview

AGRIS is an academic robotics project built around a simple question: can a mobile rover reliably track and follow a target using vision alone, coordinating a camera feed, a tracking algorithm, and motor control across a wireless link? The project brings together computer vision, control theory, and embedded systems on a physical Mecanum-wheel platform.

Problem / Concept

The core concept behind AGRIS was to explore how a low-cost rover platform could perform target tracking using only a camera stream and software-based vision processing, rather than expensive dedicated sensors. The project treats this as a systems integration problem — vision, logic, and hardware all had to work together in real time.

Technical Approach

An ESP32-CAM streams an MJPEG video feed to a Python application, where OpenCV processes each frame to locate the target. A PID-based tracking loop converts the target's position into movement corrections, which are sent as UDP servo commands to the rover's control system. Teleoperation support was added using a DualShock 4 controller through Bluepad32, allowing manual override alongside autonomous tracking.
